# 🏥 Hospital Management System (MERN Stack)

A full-featured Hospital Management System built using the **MERN** (MongoDB, Express.js, React.js, Node.js) stack.  
This project streamlines hospital operations such as patient registration, doctor management, appointment scheduling, and medical record handling — all within a modern, secure web interface.

---

## 🚀 Tech Stack

**Frontend:** React.js, Redux,  Material UI  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (with Mongoose ODM)  
**Authentication:** JWT (JSON Web Token)  
**Other Tools:** Axios, bcrypt.js, dotenv, nodemon, cors, mongoose

---

## 📋 Features

### 👩‍⚕️ Admin
- Manage doctors, staff, and departments  
- View patient appointments  
- Access and edit patient records  
- Generate reports and analytics  

### 🧑‍⚕️ Doctor
- Manage daily appointments  
-accept or reject appointments
-view patient details  

### 🧍 Patient
- Register and log in securely  
- Book appointments  

### ⚙️ General
- Role-based authentication (Admin / Doctor / Patient)  
- Responsive UI for desktop and mobile  
- RESTful API with structured error handling  
- Secure password hashing and JWT-based sessions
